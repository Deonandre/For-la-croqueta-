# Le Procès de Cunégonde

Procès littéraire de Cunégonde de Thunder-ten-tronckh, pour l'activité de
Français A HL sur *Candide ou l'Optimisme* de Voltaire (1759).

| Fichier | Usage |
| --- | --- |
| `index.html` | Version interactive : filtrage par rôle, mode répétition avec enchaînements, index des références. |
| `Proces_de_Cunegonde.docx` | Version Word à imprimer et à distribuer au groupe. |

## Contenu

Sept actes, 66 répliques, 61 renvois au roman répartis sur 15 chapitres.

1. Ouverture de l'audience — le juge énonce les trois chefs d'accusation
2. Réquisitoire introductif — le paravent (ch. I), l'Eldorado (ch. XVIII), la promesse (ch. XXIX–XXX)
3. Plaidoirie introductive — la défense démonte chaque chef
4. Interrogatoire de Cunégonde — contre-interrogatoire des deux parties
5. Audition de Candide — l'aveu qui fait basculer le procès
6. Conclusions des parties et dernier mot de l'accusée
7. Verdict

Annexes : index des références chapitre par chapitre, conseils de jeu par rôle,
réponses de secours aux questions imprévues.
