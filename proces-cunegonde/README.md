# Le Procès de Cunégonde

Procès littéraire de Cunégonde de Thunder-ten-tronckh, pour l'activité de
Français A HL sur *Candide ou l'Optimisme* de Voltaire (1759).

| Fichier | Usage |
| --- | --- |
| `Proces_de_Cunegonde.docx` | Script d'audience minuté : chaque réplique numérotée, son horaire de départ, son signal d'entrée, plus une fiche par élève. |
| `index.html` | Version interactive : filtrage par rôle, mode répétition avec enchaînements, index des références. |
| `generer_docx.py` | Régénère le `.docx` à partir de `index.html` (`python3 generer_docx.py index.html sortie.docx`). |

## Contenu

Sept actes, 66 répliques, 60 renvois au roman répartis sur 15 chapitres.
Durée d'audience 30 min 23 s, calculée à 140 mots par minute, pauses comprises.

| V | Audition du témoin Candide | 16:36 | N° 36–59 |
| VI | Conclusions des parties | 20:31 | N° 60–65 |
| VII | Verdict | 26:34 | N° 66 |

Annexes : index des références chapitre par chapitre, conseils de jeu par rôle,
réponses de secours aux questions imprévues.
